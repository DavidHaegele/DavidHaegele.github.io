I develop and maintain open source software for the calculation and analysis of exoplanet atmosphere spectra.

line racer
======
*Role: main developer*

An open source Python package for the rapid calculation of high-resolution radiative opacities for exoplanet atmospheres. I designed and wrote the package from scratch as part of my Master's thesis with Paul Mollière; a first-author paper is submitted to the Journal of Open Source Software.

[Documentation](https://line-racer.readthedocs.io/en/latest/)

petitRADTRANS
======
*Role: maintainer & core developer*

opacities, stllar thing function...
A widely used open source Python package for calculating spectra of exoplanets and running atmospheric retrievals. I am part of the active development team: I maintain the code base and develop new features.

[Documentation](https://petitradtrans.readthedocs.io/en/latest/)
